# 0002. Local MDX Content and GSAP Interaction Stack

We use statically typed local MDX and TypeScript data schemas for case studies and publications instead of a headless CMS to eliminate runtime network latency and keep hosting costs at zero. For rich animations, we use a hybrid stack of GSAP (for high-performance scroll triggers, timeline sequencing, and canvas-based cursor effects) and Motion/React 19 for declarative UI state transitions.
