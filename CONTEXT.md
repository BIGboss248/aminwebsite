# Amin Jamali Portfolio & Lab Context

The domain model for Amin Jamali's personal portfolio, interactive engineering lab, and digital credentials platform.

## Language

**Case Study**:
An in-depth technical walkthrough of a production web application or peer-reviewed scientific research paper detailing architecture, methodology, performance metrics, and business/computational outcomes.
_Avoid_: Blog post, article, summary

**Lab Tool**:
A standalone, interactive browser-based networking or data engineering utility (such as IP Info Lookup or DoH Tester) demonstrating real-time systems capabilities.
_Avoid_: Demo widget, toy app, sandbox

**Trust Signal**:
Verifiable evidence of competence including peer-reviewed publications (DOIs), ORCID identity, verified vendor certifications (Google, IBM, Vercel), and empirical production metrics (Lighthouse scores, conversion lifts).
_Avoid_: Vanity badge, icon, sticker

**Locale**:
The active language and layout direction context (`en` for English LTR, `fa` for Persian RTL) applied globally across typography, navigation, and content.
_Avoid_: Translation mode, dialect
