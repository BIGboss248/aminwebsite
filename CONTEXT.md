# Amin Jamali Portfolio & Lab Context

The domain model for Amin Jamali's personal portfolio, interactive engineering lab, and digital credentials platform.

## Language

**Case Study**:
A technical narrative of a delivered web application detailing client problem statement, system architecture, engineering challenges, and verifiable Core Web Vitals performance benchmarks.
_Avoid_: Code dump, business revenue report, blog post

**Research Publication**:
A peer-reviewed scientific paper on machine learning, NLP, or computational finance, identified by a permanent DOI and linked to an ORCID record within the resume domain.
_Avoid_: Project, blog article, essay

**Lab Tool**:
A standalone, interactive browser-based networking, censorship diagnostic, or device fingerprinting utility demonstrating real-time systems capabilities.
_Avoid_: Demo widget, toy app, sandbox

**DoH Prober**:
A diagnostic mechanism in the DNS over HTTPS tester that benchmarks major and alternative resolvers directly from the client's browser, auto-detecting censorship blocks, DNS poisoning, and valid query paths (`/dns-query`, `/resolve`, `/query`) on custom user domains.
_Avoid_: DNS lookup box, ping tester

**Identity Leak Vector**:
A diagnostic probe testing points where a client's true identity, origin, or physical location can bypass proxy/VPN tunnels (including WebRTC interface leaks, System-vs-IP timezone mismatches, proxy headers, and DNS leaks).
_Avoid_: Privacy score, anonymity rating

**Device Fingerprint**:
A deterministic client-side signature compiled from Canvas 2D rendering, WebGL GPU parameters, AudioContext waveform, and hardware capabilities (CPU cores, RAM) used to track users regardless of IP changes.
_Avoid_: Cookie ID, browser tag

**Trust Signal**:
Verifiable evidence of competence including peer-reviewed publications (DOIs), ORCID identity, verified vendor certifications (Google, IBM, Vercel), and empirical production metrics (Lighthouse scores, conversion lifts).
_Avoid_: Vanity badge, icon, sticker

**Locale**:
The active language and layout direction context (`en` for English LTR, `fa` for Persian RTL) applied globally across typography, navigation, and content.
_Avoid_: Translation mode, dialect
